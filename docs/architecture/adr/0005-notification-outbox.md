# ADR-0005: Файловий outbox для недоставлених нотифікацій

- **Номер:** 0005
- **Статус:** Accepted (2026-11-27, [[change/ccb-protocol#ccb-2026-11-27]]). Замінює ADR-0002 у частині «нотифікацію, що не дійшла, втрачено».
- **Компонент:** [[architecture/sdd#sdd-notifier|SDD: Клієнт нотифікатора]], [[architecture/isd#isd-env|ISD: змінні оточення]]
- **Підстава:** [[incidents/INC-001]], [[change/RFC-001]], [[change/IA-001]]

## Контекст

ADR-0002 свідомо приймав втрату нотифікації після 3 спроб і називав умову перегляду: «потрібна гарантована доставка (outbox)». INC-001 цю умову виконав: за 60.5 с відмови нотифікатора 163 нотифікації втрачено назавжди, і жоден сигнал не спрацював.

## Розглянуті альтернативи

| Варіант | За | Проти |
|---|---|---|
| Лишити як є (ADR-0002) | нуль змін | втрата незворотна, SLO не контролюється |
| Брокер повідомлень (Redis, RabbitMQ) | гарантована доставка, воркери | нова інфраструктура і точка відмови для одного процесу |
| **Файловий outbox JSONL + ручний replay (обрано)** | без нової інфраструктури, узгоджено з [[architecture/adr/0001-json-file-storage]], файл входить у бекап | replay не автоматичний; один процес (блокування в межах процесу) |
| Фоновий воркер з автоматичним replay | без ручної дії | дублі, доки ідемпотентність приймача не підтверджено (ризик R1 в IA-001) |

## Рішення

- Після fallback `notify_task_created` дописує `Task.to_dict()` рядком у `NOTIFIER_OUTBOX`. Помилка запису не ламає `POST /tasks`: вона рахується як `result="lost"`.
- `python -m tasks.notifier_outbox replay` перейменовує файл, надсилає кожен запис один раз і повертає в outbox недоставлені.
- Результат кожної доставки експортується як `notifier_delivery_total{result}`, довжина черги як `notifier_outbox_pending`.

## Наслідки

- **Плюси:** втрата нотифікації стає затримкою; відмову видно за ≤ 2 хв (`NotifierFallbackRatio`).
- **Мінуси:** replay ручний (умова CCB C3); outbox росте під час тривалої відмови; кілька процесів uvicorn потребуватимуть файлового блокування.
- **Тести:** `tests/test_incident_inc001.py`, `tests/test_notifier_outbox.py`, `tests/test_backup.py::test_outbox_is_backed_up_and_counted_by_lines`.
- **Коли переглянути:** приймач підтвердив ідемпотентність за `id` (тоді автоматичний replay, TD-A1) або з'явився брокер.
