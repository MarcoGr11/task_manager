## 2. Онбординг за 5 кроків

1. Клонувати репозиторій і створити venv на Python 3.13. Виконати `pip install -r requirements.txt` і `git config core.hooksPath .githooks`. Потрібні gitleaks і radon.
2. Виконати `python -m pytest`. Очікуваний результат: усі тести зелені.
3. Виконати `python -m tasks.seed_users`, запустити `uvicorn mock_notifier.server:app --port 9100` і `uvicorn tasks.api:app --port 8000`, потім `curl localhost:8000/health`.
4. Прочитати README, SDD §2-3, ISD §3 і §5 та обидва ADR (близько 15 хвилин).
5. Перша зміна: змінити код і документацію в одному коміті. Перевірити `python scripts/doc_audit.py`, очікується exit 0. Коміт має пройти хук: gitleaks і CC ≤ 10.
